Here are the step-by-step instructions for **Wazuh VirusTotal Integration for Malware Detection**:

1. **Obtain VirusTotal API Key:** Required for querying VirusTotal REST API.
1. Go to [VirusTotal](https://www.virustotal.com/) and sign up for a free account (or log in).
2. Click on your profile icon in the top-right corner and select **API Key**.
3. Copy your **Public API Key**.


2. **Configure File Integrity Monitoring (FIM):** Ensures files in target directories generate FIM alerts for VirusTotal to process.
Ensure that File Integrity Monitoring (FIM) is enabled and watching your target directories (such as `Downloads` or `/tmp`):

* **On Wazuh Dashboard (Centralized Group Configuration):**
1. Navigate to **Management** → **Groups** → Select your agent group.
2. Edit `agent.conf` and ensure the `<syscheck>` block monitors your target directories with `realtime="yes"`.


* **On Wazuh Manager / Local Agent (`ossec.conf`):**

```xml
<syscheck>
  <disabled>no</disabled>
  <directories realtime="yes">C:\Users\*\Downloads</directories>
</syscheck>

```


3. **Enable VirusTotal Integration on Wazuh Manager:** Path: /var/ossec/etc/ossec.conf on Wazuh Manager.
1. Open a terminal on your **Wazuh Manager** server as `root` or using `sudo`.
2. Open the main configuration file:

```bash
sudo nano /var/ossec/etc/ossec.conf

```

3. Add the following `<integration>` block inside the main `<ossec_config>` section:

```xml
<integration>
  <name>virustotal</name>
  <api_key>YOUR_VIRUSTOTAL_API_KEY</api_key>
  <group>syscheck</group>
  <alert_format>json</alert_format>
</integration>

```

*Replace `YOUR_VIRUSTOTAL_API_KEY` with the API key copied from VirusTotal.*


4. **Restart Wazuh Manager:** Applies new integration settings.
Restart the Wazuh Manager service to apply the integration:

```bash
sudo systemctl restart wazuh-manager

```


5. **Test Malware Detection with EICAR Sample:** Triggers real-time FIM scan and API check.
1. On a monitored endpoint, download or place an **EICAR test file** into the monitored directory:
* **Linux:** `curl -Lo /tmp/eicar.com [https://secure.eicar.org/eicar.com](https://secure.eicar.org/eicar.com)`
* **Windows:** Download the EICAR test file into the monitored `Downloads` folder.


2. FIM detects the new file creation and automatically sends its hash to VirusTotal.


6. **Verify Alerts in Wazuh Dashboard:** Confirms threat detection alerts.
1. Log in to your **Wazuh Dashboard**.
2. Go to **Modules** → **Threat Detection and Response** → **VirusTotal** (or **Security Events**).
3. Look for alerts generated by VirusTotal rules (such as **Rule ID 87105**: *VirusTotal: Alert - Source file is malicious*).
